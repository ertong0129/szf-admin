一、Mac
1. 解压整个文件夹。
2. 双击「洪武风云录」图标，或右键「启动游戏.command」→ 打开。
   若提示无法验证开发者：系统设置 → 隐私与安全性 → 仍要打开。
   若提示没有执行权限，在终端执行：
   chmod +x 启动游戏.command start.command
3. 浏览器会在服务就绪后自动打开。
4. 测试号 demo / 123456。
5. 不要关终端窗口（或程序坞里的图标），关掉就停服。

二、没有 Node / Python 时
启动器会尽量用本机已有的 Node 或 Python 起本地服。
两者都没有时，会直接打开 index.html，图片应仍能显示，但没有服务端存档。
Mac 一般自带 python3；也可装 Node：https://nodejs.org

三、操作
点右侧「任务追踪」：自动寻路（跨图会先走传送点，到达后自动对话/打怪/采药）
左键点地：斜视 3D 地面自动寻路（黄圈）
左键点怪 / NPC：攻击或对话
底栏红钮「商」：商城    小地图可点击走路
1-6 技能   Q/R 吃药   F 拾取   Z 挂机   C/B/V/J 角色背包技能任务

四、卡住了
旧存档若出生在房子里，重新进游戏会自动拉到空地。
也可删浏览器本站数据后重建角色。
若页面打开了但图片全无：先看启动窗口是否还在、地址是不是 127.0.0.1:8088，不要用文件协议刷新。
若 jsDelivr 还是旧包，用上面的 gh-proxy 备用链接。
登录页应显示「已连接本地服务端 v20260816c」。若没有这个版本号，说明还在跑旧包，请删掉解压目录后重新下载。
终端窗口必须一直开着；关掉就停服。异常退出会自动重启。
